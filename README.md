# Dikshit Solanki — Portfolio Website

A cinematic, interactive portfolio website featuring a high-performance scroll-driven frame animation, modern typography, and structured showcase for content creation, video editing, thumbnail design, and AI-assisted creative production.

## 🚀 Features

- **Smooth Scroll-Driven Frame Animation:** 240-frame sequence rendered via HTML5 `<canvas>` with devicePixelRatio high-DPI scaling and proportional cover sizing.
- **Buttery-Smooth Motion:** Powered by GSAP `ScrollTrigger` with inertia scrubbing (`scrub: 0.9`) and vanilla RAF linear interpolation fallback.
- **Authentic Portfolio Showcase:** Structured case studies for YouTube thumbnails, storytelling video editing, graphic design, and AI concept projects.
- **Client-Focused Services:** Detailed breakdown of Video Editing, Thumbnail Design, Graphic Design, AI Creative Production, and Content Research & Writing.
- **Interactive Contact:** Direct email (`dikshitsolanki90@gmail.com`), WhatsApp integration, and interactive project inquiry form.
- **Fully Responsive & Dark Aesthetic:** Clean, premium dark UI (`#090909`) with energetic orange accents (`#ff551f`).

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Animation & Scrubbing:** GSAP 3, ScrollTrigger
- **Typography:** Plus Jakarta Sans & Space Grotesk
- **Local Server:** Lightweight multi-threaded PowerShell / .NET HTTP Server (`serve.ps1`)

## 💻 Running Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/dikshit06kumar-cmd/dikshit-solanki.git
   cd dikshit-solanki
   ```
2. Start the local server:
   ```powershell
   powershell -ExecutionPolicy Bypass -File serve.ps1
   ```
3. Open `http://localhost:3000/` in your browser.
*(Or open `index.html` directly in any web browser).*
